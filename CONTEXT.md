# Design Thinking App Workspace

Build UX case studies and optional React apps from rough user problems.

## Task Routing

| Task Type | Go To | Description |
|-----------|-------|-------------|
| Problem intake | `stages/01-problem-intake/CONTEXT.md` | Frame the raw idea as a researchable UX challenge |
| Research | `stages/02-research-and-validation/CONTEXT.md` | Validate the problem and synthesize evidence |
| Empathize | `stages/03-empathize-artifacts/CONTEXT.md` | Create interviews, personas, stories, journeys, and empathy maps |
| Define | `stages/04-define-artifacts/CONTEXT.md` | Produce problem, needs, hypothesis, and value artifacts |
| Ideate | `stages/05-ideation-and-wireframes/CONTEXT.md` | Generate solution directions and wireframe requirements |
| Case study | `stages/06-case-study-assembly/CONTEXT.md` | Assemble the portfolio-ready UX case study |
| App build | `stages/07-react-app-build/CONTEXT.md` | Build the optional React/Vite/Tailwind app |
