# Value Framework

Use this framework to check whether each artifact and the final case study produces real portfolio value.

## Value Types

- Evidence-backed: decisions trace to research signals or explicit assumptions.
- Human-centered: artifacts represent user goals, context, feelings, and barriers.
- Actionable: outputs can guide a design or build decision.
- Portfolio-ready: the narrative is credible, concise, and reviewable.
- Buildable: app requirements can be implemented as a realistic prototype.

## Check

Before saving a major output, name which value types it delivers and revise weak sections.
