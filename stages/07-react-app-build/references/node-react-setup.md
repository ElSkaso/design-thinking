# Node And React Setup

## Required Tools

- Node.js 18 or newer
- npm or pnpm
- A modern browser

## Verify

```bash
node --version
npm --version
```

## Workspace Use

The app build stage uses Node and npm or pnpm to create, install, run, build, and test the local React/Vite/Tailwind app.

## Optional Tools

- Git/GitHub for versioning and deployment handoff
- Playwright for browser QA
- Supabase or Firebase when backend features are enabled

## Optional Tool Setup

If a run needs Supabase, Firebase, GitHub deployment, or Playwright QA, ask the user which service they prefer and follow the current official setup guide for that service. Keep backend and browser QA optional unless the project requires them.
