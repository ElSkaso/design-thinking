# Intake Format

## Project Brief Structure

Write the artifact with exactly these content sections:

```markdown
# Project Brief: [Project]

## Problem Frame

## Target Users

## Context And Constraints

## Known Facts

## Assumptions

## Open Questions

## Research Questions

## Success Signals
```

Keep the brief focused on the project result. Include evidence basis or confidence only when already known and useful.

## Default Problem

Collect the problem statement from the user at the start of each run. Refine it through conversation before saving output.
